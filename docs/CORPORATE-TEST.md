# Corporate test — 0.1.0-corp-test

1. Open the repository's Actions tab.
2. Open the successful Build PCD Excel XLSM run.
3. In Artifacts, download PCD-Excel-Version.
4. Extract the downloaded ZIP.
5. Open PCD-Excel-Version-0.1.0-corp-test.xlsm in desktop Microsoft Excel.
6. If Excel shows a macro/security banner, follow the company's normal policy. Do not lower global security settings.
7. Open the Magic Import sheet.
8. Paste the SAFE text into the large input area.
9. Verify the populated fields on Intervention en cours.
10. For the first test, compare Infrastructure, ID intervention, OAG ID, ID client, client, GSM, Description, Adresse principale, LOM key, CID and Status.

This is an early test checkpoint, not the production PCD tool or final updater.
